## How I work

I use AI as an engineering multiplier rather than a replacement for product judgment. I start from the problem, build the smallest useful version, inspect the result, find root causes when something fails, and turn one-off fixes into reusable system behavior.

Some of my main projects remain private because they contain production configuration, internal workflows, business logic, or proprietary content. The public case studies above document the product decisions, architecture, and engineering work without exposing sensitive implementation details.
